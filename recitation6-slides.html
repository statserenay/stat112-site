The toolbar contains a number of buttons that enable you to perform various tasks with a click, such as Save, Undo, and New Worksheet. In the toolbar, there are three important buttons: The Tableau icon: This brings you back to the start screen, where, among other things, you can add additional data sources. Undo: This allows you to go back a step so you can safely try out different ideas. You can go back as many steps as you like. Redo: This allows you to restore any undone actions.

Marks Card: The visualization can be designed using the Marks card. The Marks card can be used to change the data components of the visualization, such as color, size, shape, path, label, and tooltip.

Dimension Shelf: This shelf contains all the categorical columns, for example, categories, segments, gender, and name.

Measure Shelf: This shelf contains all the numerical columns, such as profit, total sales, and discount.

The Show Me panel suggests suitable visuals for the chosen variable.

Filters Shelf: You can choose which data to include and exclude using the Filters shelf. For example, you might want to analyze the profit for each customer segment, but only for certain shipping containers and delivery times. You can create a view like this by placing fields on the Filters shelf.

Worksheet: In the workbook, the worksheet or canvas is where the actual visualization appears. The worksheet or canvas contains information about the visual’s design and functionality.

Page Shelf: This shelf is used for joining pages and creating animations. We will come back to it later.

RQ3 step 3: on a log scale, the box plot shows only the real outliers

1 Shape: histogram

2 Center and spread: Summary card

3 Outliers: box plot

Why take the log of Sales first? Sales is strongly right-skewed (skewness 13): half of all orders are under $54, but the largest is $22,638. On the raw scale the box is squashed near $0, and every order above about $500 (Q3 + 1.5 × IQR) is flagged as an outlier: hundreds of points. The log compresses large values, so the distribution becomes close to symmetric and the box becomes readable. Adding 1 avoids LOG(0), which is undefined; a $0 order maps to 0. A. Analysis > Create Calculated Field: name it Log_Sales, enter LOG([Sales]+1). B. Drag Log_Sales to Rows and pick Box-and-whisker plot in Show Me.

Reading the log scale: 1 = $10, 2 = $100, 3 = $1,000, 4 = $10,000

1.74 Median ≈ $54

1.26–2.32 Box ≈ $17–$210

3.93 Upper whisker ≈ $8,500

Only orders above about $8,500 remain outliers. Check these few very large orders before deciding whether to keep them.

PART 3 Building a dashboard

Femicide in Turkey, 2008–2020: four worksheets combined into one interactive dashboard and published to Tableau Public.

A dashboard combines several views so viewers can compare them at once

A good dashboard aligns attention on the key message, uncovers insights and speeds up decisions. Four rules:

Know purpose and audience

Decide what the dashboard must say, and how familiar viewers are with the topic.

Use the top-left corner

Viewers scan from the top left, so put the most important view there.

Limit the content

At most four views; more makes the dashboard hard to read.

Add interactivity

Filters and highlight actions invite viewers to explore.
